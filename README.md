# Artifacts Player

A Node.js project that runs as a cli to play and automate the [Actifacts MMO game](https://www.artifactsmmo.com/).

## About

Artifacts is a game you can play only through a REST API meaning that every action you take such as moving your character, fighting, or turning in a quest, must be an API call.

This project aims to automate character behaviors using directed graphs. Currently behavior recipes are each defined by hand, but subgraphs can be build to compose more complex behavior. In the future I might explore other character AI approaches such as behavior trees.
